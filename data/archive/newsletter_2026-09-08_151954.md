### 深度排雷一：Fastlane 築起的免費使用者壁壘與蘋果憑證地獄

NoMac.App [⁴](https://nomac.app) 標榜「為 AI Agent 打造的 iOS CI/CD」，Gote [⁵](https://news.ycombinator.com/item?id=49600397) 則賣極簡 Markdown CLI。兩者共同踩中紅線：**參考免費基建、碰硬體憑證、賣給最愛白嫖的開發者**。

**戳破願景**：AI Agent 需要 CI/CD 是偽命題，Agent 只需呼叫 Fastlane/GitHub Actions/Bitrise 現成 API。NoMac 解決的「簽名憑證自動化」本質是蘋果開發者帳號的雙因子驗證、裝置辨識碼（UDID）管理、Provisioning Profile 過期輪替——這是**極度依賴實體裝置農場與人工值守的髒活**。

**落地摩擦力**：目標客戶是獨立 iOS 開發者，習慣 Fastlane 免費腳本 + GitHub Actions 免費額度。要他們付費訂閱，錨定成本是「零元」。若錨定「省下工讀生維護憑證」，月薪 4 萬台幣（含健保勞保），攤到單專案成本極低，根本養不起 SaaS 訂閱。更致命的是：蘋果隨時可能推出「企業級簽名自動化」免費內建（如 Xcode Cloud 擴展），單點功能瞬間歸零。

**巨頭抹殺路徑**：GitHub Actions macOS Runner 免費額度加碼、Fastlane 官方維護 `match`/`sigh` 自動簽名、Xcode Cloud 深度整合。三個月內免費方案覆蓋率超 90%。

**SOS 4.2 生死裁決**：踩中「實體裝置農場依賴（間接）」、「平台單點失效風險」、「客戶零付費慣性」三條紅線。悲觀情境全台 20 家買單，月費錨定「免費替代品」= 0 元，ARR = 0。**【否決】**。

**特種部隊突圍**：無。此領域無 Tiny Wedge，只有無盡的憑證報錯與蘋果審核指南變更。創辦人這週末應去寫 Fastlane Plugin 開源積累信任，而非寫計費系統。

### 深度排雷二：Token 變電商 SKU、Agent 吞噬維護邊際成本歸零

Kimi/MiniMax 入駐天貓賣 Token [¹](http://www.geekpark.net/news/369875)，OpenAI 內部已用 Coding Agent 取代人力維護開源專案 [⁶](https://www.latent.space/p/pr-not-welcome)，GPT-6 Astra 以 2.5 倍 Token 價換單任務成本暴跌 [²](https://www.latent.space/p/ainews-gpt-6-astra-openais-biggest)。三組訊號指向同一結論：**模型推理與程式碼維護雙雙商品化，邊際成本趨近零**。

**戳破願景**：創業者幻想「垂直 Micro-SaaS 封裝 Prompt + RAG 收訂閱」。現實是：模型廠商直接在電商平台按量售 Token，平台廠商（微信、Notion、VS Code）內建 Agent 免費送。你的「封裝價值」被雙向擠壓。

**落地摩擦力**：B2B 客戶替代方案是「GitHub Copilot Business $19/月/席」或「Cursor Pro $20/月」。你的獨立產品若無私有資料護城河（如醫療病歷、法律判例、專利庫），客戶零遷移成本直接切走。銷售鏈條長、需統編發票、法務審核 DPA，單客戶獲取成本（CAC）極易超過 LTV。

**巨頭抹殺路徑**：Vercel AI SDK 內建 RAG 模板、Supabase pgvector 免費向量庫、OpenAI Assistants API 直接托管 Thread/Tool/Retrieval。三個月內「標準化 RAG 管線」變成一鍵部署模板。

**SOS 4.2 生死裁決**：踩中「無私有骯髒資料」、「巨頭免費隨附」、「長決策鏈/需法務審核」紅線。悲觀 20 家客戶，月費錨定 Copilot $19 ≈ 600 台幣，ARR = 20 * 600 * 12 = 14.4 萬，**遠低 120 萬門檻**。**【否決】**。

**特種部隊突圍**：唯一縫隙在「巨頭碰不觸、不願公開、但極痛」的私有流程。例如：台鐵調度員口頭傳承的「臨時加車規則」、夜市攤商手寫記帳的「食材損耗經驗值」。這週末別寫代碼，拿 Google 表單做成「結構化訪談紀錄樣張」，跑去實體現場問老闆：「這張表若能自動變成調度建議/採購單，您願意月付 3,000 元嗎？」不願簽意向書即刻止損。
