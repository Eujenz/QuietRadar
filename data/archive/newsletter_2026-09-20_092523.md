### 當巨頭把「AI 助理」打包進作業系統，獨立開發者還能在縫隙裡賣什麼？

上週 Meta 的 Muse 登頂美區 App Store，蘋果、微軟、谷歌的原生 AI 代理已深度繫結作業系統層級的郵件、行事曆、檔案系統。這不是科幻預告，而是下個季度的預設選項。當「喚醒詞」變成系統許可權，任何仍停留在「聚合免費 API、包裝 Prompt、做成 Electron 殼」的創業專案，其護城河已在發布會結束前蒸發。本期專欄不聊宏大願景，只算兩筆帳：一筆是「自建平臺」的隱形成本，另一筆是「規格驅動」的槓桿收益；再補兩則跨界情報——一個關於創辦人如何把書變成技能，另一個關於個資外洩如何催生新的信任基建。

### 案例一：ENZO 踩入「本地 AI 平臺」的隱形開銷

GitHub 上冒出一個叫 ENZO 的開源專案 [¹](https://github.com/theguysudo/ENZO)，標語是「開箱即用的本地 AI 平臺」，整合兩千多個免費模型 API，內建 Agent 分頁、Gmail/Drive/Calendar 串接、程式碼模式，聽起來像是獨立開發者的夢幻瑞士刀。但剝開 README，殘酷的現實是：免費 API 的速率限制、Token 額度、模型下線頻率，全都要創辦人自己寫排程器去輪詢、去換 Key、去處理 429 錯誤；OAuth 權杖過期重新整理、Google 隨時收緊範圍審核，更是讓「零維運」變成「全職維運」。真實客戶端不在 Hacker News，而在於不願把公司機密餵給 OpenAI、又沒工程師能自架 Llama 的中小企主——他們現在的替代方案是：花 4 萬臺幣請一個實習生手動複製貼上，或是直接忍受資料外洩風險。巨頭的抹殺路徑不需要三個月：Windows Copilot 已能原生讀 Outlook、寫 Word、跑 Python；macOS Sequoia 的 Apple Intelligence 直接掛載 App Intents。ENZO 這類「聚合層」若不深入基層到「垂直領域的合規資料管線」（如：醫療紀錄脫敏後再餵模型、會計憑證自動對帳），Micro-TAM 只剩下幾百個隱私偏執狂，月費 20 美元也撐不起一個人的燒雞腿飯。這週末別寫程式碼，去寫一份「ENZO 託管部署 + 合規資料清洗 SOP」的 Notion 報價單，掛上 Stripe Payment Link，發給 50 位臺灣醫療/法務/會計獨立工作室老闆，沒人買就砍專案，別在沉沒成本裡寫 Issue。

### 案例二：SDD 讓「規格」成為唯一資產，程式碼只是廢料

掘金熱文展示如何用 Claude Code 搭配 OpenSpec 把 AI 寫程式碼變成流水線 [²](https://juejin.cn/post/7627448009643966483)。核心洞見不在工具鏈，而在於權力倒置：過去工程師寫程式碼再寫檔案，現在創辦人寫 Spec（OpenAPI/Markdown/測試案例），AI 生成程式碼、測試、CI/CD 全自動跑完。這對一人公司意味著什麼？意味著你的核心資產不再是 GitHub 上的私有倉庫，而是那份能精準描述「業務規則、驗收標準、邊界條件」的 Spec 檔案。程式碼變成了可隨時丟棄、重寫的「編譯產物」。真正的商機在於：把垂直領域的最佳實踐封裝成「Spec 模板包」販售。例如：「訂閱制 SaaS 計費邏輯 Spec 包」（含按比例計費、升降級、發票、稅務、失效重試），定價 9,900 臺幣，目標客群是想自己架帳務系統卻不敢信 AI 亂寫的獨立開發者——全臺約 2,000 人，轉換 1% 就有 20 萬月收，邊際成本趨近零。驗證道具：這週末用 GitHub Pages 架一個靜態頁，放三個 Spec 片段截圖 + 一段 Claude Code 實測影片 + Gumroad 購買鈕，發到 PTSoft、Dcard 程式設計版、Discord 獨立開發群，看有沒有人掏錢。

### 跨界漫遊一：QBS——把「讀書」變成「可執行技能」的元協議

人人都是產品經理上一篇關於 QBS（Question → Book → Skill）的實戰分享 [³](https://www.woshipm.com/ai/6466898.html)，乍看是個人效率技巧，實則是創辦人「時間脫鉤」的核心操作手冊。作者把「時間管理」這個模糊實質困擾丟給模型，模型找來《Make Time》完整閱讀相關章節，萃取出「每天只選一個重點、建立雷射模式、能量管理」等具體規則，再用新任務驗證。這不就是「決策層中介軟體」在創辦人腦內的部署嗎？一人公司最稀缺的是創辦人注意力，QBS 強迫你把隱性知識顯性化、標準化、可驗證化。下次面對「SEO 關鍵字規劃」、「冷郵件轉化率最佳化」、「稅務架構規劃」這類非核心但必須懂的領域，別再看 10 小時 YouTube，直接丟給 QBS 流程，產出一份「可直接執行的 SOP 檔案」存入知識庫，下次遇到同類問題直接呼叫。這才是 AI 時代創辦人應該建立的護城河：不是會寫 Prompt，而是擁有最豐富、最高品質、經過實戰驗證的「Skill 庫」。

### 跨界漫遊二：IKEA/桂冠假續訂詐騙——當個資成了武器，信任基建就是生意

數位時代報導 IKEA、桂冠等品牌遭冒名「自動續訂」詐騙，詐騙信夾帶真實姓名、地址、訂單編號 [⁴](https://www.bnext.com.tw/article/92305/ikea-laurel-june1st-airspace-subscription-scam-data-leak)。這不是單純資安新聞，而是「訂閱制經濟」信任基建崩塌的前兆。當消費者不敢點郵件裡的「管理訂閱」連結，品牌方的 LTV（生命週期價值）就被詐騙集團偷走。機會在於：為中小型 D2C 品牌打造「零知識驗證層」——使用者收到續訂通知，不需點連結、不需輸入帳密，只需在品牌官方 App/Line 官方帳號/簡訊驗證碼中確認「是我本人」，即可完成續訂/取消/升級。技術棧：WebAuthn/Passkey + 簡訊 OTP 輪播 + 品牌專屬驗證頁面。Micro-TAM：臺灣/香港/新加坡約 3,000 家年收 1,000 萬以上的 D2C 品牌，替代成本是自建會員系統的 50 萬開發費 + 持續資安維運。驗證道具：一份「訂閱製品牌防詐騙信任度自評表」Google 表單 + 一頁式解決方案架構圖，這週末約 3 位認識的電商創辦人喝咖啡，請他們填表、聊實質困擾、收 5 萬定金預售 PoC。

### 主筆總結：一人公司的防守邊界

巨頭佔據了「平臺層」與「入口層」，獨立開發者唯一的生存空間在「垂直領域的合規資料管線」與「高信任度的決策執行標準」。別建平臺，建 Spec；別賣工具，賣驗證過的 Skill；別信任郵件，建驗證層。現金流不脫鉤，一切都是愛好者自嗨。守住這三條線，才能在 AI 浪潮裡不被沖成泡沫。
